# EarthMC Tracker

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org)

An automated tracker and monitoring tool for the **EarthMC** Minecraft server network. This tool hooks into EarthMC's public map data and APIs to track real-time changes in player activity, nation/town statistics, geopolitical shifts, and server states, delivering updates and historical logs.

## 🚀 Features

- **Real-Time Tracking:** Continually monitors player counts, online status, and location vectors where available.
- **Geopolitical Monitoring:** Tracks the rise, expansion, and fall of towns and nations across the map.
- **Historical Logging:** Stores historical data to observe demographic trends, player spikes, and territorial expansions over time.
- **Discord Integration (Optional):** Sends real-time webhook notifications for significant events, such as a major town falling, a player logging on/off, or nation status changes.
- **Lightweight & Efficient:** Optimized to parse map data efficiently without putting a heavy load on system resources.
